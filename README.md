# air-quality-analysis-of-indian-cities
Data analysis and machine learning project to predict the air quality trends across various Indian cities.

## About the project:
This project analyzes Air Quality Index (AQI) data from multiple Indian cities to identify trends, regional patterns, and seasonal variation using Exploratory data analysis, data cleaning, visualization and trend analysis. I am trying to achieve this goal by using data that is publicly available and accessible.  


## The purpose of this project:
I chose this project beacuse air pollution has become a major problem across many parts of India. This problem can be serious for everyone being exposed to air pollution. This  project can help me gain some insights and patterns about the air quality of India.

## About the data:
The data comes from open sources like [(https://airquality.cpcb.gov.in/AQI_India/),  Central Pollution Control Board (CPCB), Government of India. Publicly available AQI datasets (Oct–Nov 2025) were downloaded to run the analysis
The data consists of various pollutanats (such as PM2.5, PM10, NO2, NH3 etc) with their sources.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Key Findings
- AQI levels increased from October to mid-November as winter approached.
- Cities in the NCR region showed consistently higher pollution levels than other regions.
- Clear regional clustering of high AQI values.
- Many cities came under poor-hazardous AQI categories.

## Limitations
- Short time range of data.
- Missing AQI values for certain cities.
- Limited station coverage in certain regions.

## Possible extensions:
- More data across multiple days and years can be included to extend the lifespan of the data and improve the accuracy of the project.
- Machine  learning alghorithms could be deployed to predict AQI levels in the future.
- Numerous environmental and meteorological data could be added (such as wind speed, temparature, precipitation).
