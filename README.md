# air-quality-analysis-of-indian-cities
Data analysis and machine learning project to predict the air quality trends across various Indian cities.

## About the project:
This project aims to analyse the air pollution trends across various Indian cities, using data analysis and machine learning. I am trying to achieve this goal by using data that is publicly available and machine learning algorithms.

## The purpose of this project:
I chose this project beacuse air pollution has become a major problem across many parts of India. This problem can prove to be serious for everyone being exposed to air pollution. This  project can help me gain some insights and patterns about the air quality of India.

## About the data:
The data comes from open sources like [(https://airquality.cpcb.gov.in/AQI_India/) , (https://www.aqi.in/in/dashboard/india) , (https://openaq.org/).
The data consists of various pollutanats (such as PM2.5, PM10, NO2, NH3 etc) with their sources.
